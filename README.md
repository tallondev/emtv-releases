# EMTV – the simple solution

Android TV IPTV player for Xtream Codes providers (Live TV, movies, series, multiple playlists).
This repository only hosts the release APKs. Requires Android TV or an Android phone, Android 9 or newer
(phones: from version 1.2.0, landscape, touch).

## Install (Android TV)

1. On the TV install **Downloader** (by AFTVnews) from the Google Play Store.
2. Allow it to install apps: *Settings → Apps → Security & restrictions → Unknown sources → Downloader → On*
   (on some TVs: *Settings → Device Preferences → Security & restrictions*).
3. Open Downloader and enter the address of the latest APK:

   ```
   https://github.com/tallondev/emtv-releases/releases/latest/download/emtv.apk
   ```

4. Downloader downloads the file and asks to install it → **Install** → **Open**.
5. In EMTV add your playlist (server, username and password or the M3U link from your provider).

## Install (Android phone)

1. Open the address above in the phone's browser; it downloads `emtv.apk`.
2. Open the downloaded file. The first time, Android asks to allow the browser to install apps — allow it,
   go back and tap **Install** → **Open**.
3. In EMTV add your playlist.

## Updates

EMTV checks this repository at start (can be switched off in *Settings → General*) and offers new versions.
*Settings → General → Check for a new version now* checks immediately. The first time, Android asks to allow
EMTV to install apps — allow it once. Updates keep your playlists and settings.

## Uninstall

*Settings → Apps → EMTV → Uninstall*.
